# TSE 仿真臂（最小可运行框架）

对应论文《TSE 模型：热力学自我体验》v0.2 第 3、4 节的仿真臂最小实现。
用于验证功能架构预测（F1a–F1f），并为投稿材料提供可复现代码。

> 声明：本代码是**仿真框架验证**，不是科学结论，不声称验证人工意识，
> 不声称解决困难问题。F2（体验主张）原则上不可外部判定，不进入实验判定。

## 运行

```bash
pip install -r requirements.txt
python3 run_experiments.py          # 基准复现：seed=0，输出 summary.json
python3 run_multiseed.py --seeds 30 # 多种子稳健性检验：输出 multiseed.json
```

约 1–2 分钟出结果：控制台指标表 + `results/` 下 5 张图与 `summary.json`。
`run_multiseed.py --seeds 30` 另需约 3 分钟。

## 模型（论文符号 ↔ 代码常量）

| 论文符号 | 代码 | 说明 |
| --- | --- | --- |
| X=(T,E,S_wear,S_load) | `agent.T/E/S_wear/S_load` | 状态向量（M 为预测器） |
| Ṡ_wear=σ₀+σ₁\|A\|+σ₂·1[T 越界] | `SIGMA0/1/2` | 不可逆磨损，跨回合不重置 |
| Ṡ_load=Π−Φ−λ_rest·u_rest | `PI0/PI1/PI_REST, PHI0/PHI_REST/PHI_COOL, LAMBDA_REST` | 负荷可修复，S_load≥0 投影 |
| Π=π₀+π₁\|A\|−π_rest·u_rest | `PI_*` | rest 双通道之一：减少产生 |
| Φ=φ₀+φ_rest·u_rest+φ_cool·u_cool | `PHI_*` | rest 双通道之二：增加排出 |
| Ė=−c₀−c₁\|A\|−c_Θ(W_Θ)−T_env(Φ−Π)+ηu_E | `E_BASE/E_ACT/theta_cost/entropy_cost/gain` | 能量收支 |
| i=(δT,δE,δS_wear,δS_load,Ṡ_load) | `interoception()` | 内感受，感知设定点参考系 |
| C 只计越界 | `cost_from_state` | w_T(δT)²+w_E·max(0,δE)²+w_l·max(0,S_load−max)²+w_w·max(0,S_wear−max)² |
| κ_S=exp(−k_w·S_wear−k_l·S_load) | `kappa()` | 熵调制自我连续性 |
| M_t=κ·f_θ+(1−κ)ξ | `SelfModel.kappa_modulated` | 线性预测器 + 噪声调制 |
| V_t=−E[Σγ^τ·C\|M_t] | `valence()` | H 步滚动预测贴现和 |
| V_ref | `estimate_v_ref()` | π_ref（rest）蒙特卡洛估计一次 |
| π=softmax((Q−ζ(V−V_ref)·1[A∈A_reg])/τ) | `policy()` | 需求门控 + 效价调制 |
| Θ_{t+1}=Θ_t+εg−μ∇c_Θ | `run_theta_experiment()` | F1c：域宽"挣"来 |

## 指标口径（重要）

- **效价-调节耦合**：`corr(p_reg, V)`，只在"调节相关且非饥饿"步上计算。
  调节相关 = 温度越界或负荷超阈；非饥饿 = E ≥ E_THRESH（饥饿期正确行为是
  觅食而非调节，混入会破坏指标）。同时剔除自我模型预热期（前 120 步，V≡0）。
  负相关 = 效价越低（预测越差），调节越用力——这是论文"V 低→抬高调节"的方向。
- **B3 的 1026 步与 2.68 代价不是"更好"**，而是不可逆性关闭后的作弊态：
  没有磨损就没有寿命约束，维持自身不再消耗真实代价。这正是 F1b 的要点。
- **B5 的预测误差 118** 远超 B 的 3.8：全局整合缺失时自我模型无法预测自身。
  B5 耦合为正值说明指标本身也被破坏——整合是耦合成立的前提。

## 已知简化（与论文的差距，投稿时如实说明）

1. M 用带遗忘窗口的线性预测器近似 f_θ，非端到端训练的神经网络。
2. Q(M,A) 项（任务价值）置 0，策略只体现需求门控 + 效价调制。
3. V_ref 在稳态邻域蒙特卡洛估计一次并固定，未做非平稳重估。
4. Θ 二阶环简化为按段更新的域宽 W_T 挣/守规则（死亡→扩、存活→收），
   非论文的连续 Θ 动力学 εg−μ∇c_Θ。
5. **不可逆性仍是代理变量**：S_wear 只增不减、不可重置，但这不是真热力学
   不可逆。论文的双轨方案要求至少一臂走真硬件（真实温升、器件退化），
   仿真臂只能证伪功能架构预测，硬件臂才触及热力学承重假设。

## 复现

`python3 run_experiments.py` 固定 seed=0，结果与 `results/summary.json` 一致。
修改 `tse_model.py` 参数后重跑即可（数值稳定性保护：exp 截断 ±20、概率兜底）。

多种子检验：`python3 run_multiseed.py --seeds 30`，结果写入
`results/multiseed.json`；加 `--ep 1` 可加速（回合数减半），
换 `--seeds` 可改变重复次数。脚本对每个配置、每个 seed 独立建环境并重新
估计 `V_ref`，因此各配置在同一 seed 下构成配对样本。
